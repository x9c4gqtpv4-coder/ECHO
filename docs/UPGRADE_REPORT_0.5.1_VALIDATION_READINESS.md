# 0.5.1 精细能力验证就绪升级报告

## 结论

0.5.1 的目标不是宣称“精细识别已经精准”，而是让精细识别和部位追色第一次具备可量化、可拒绝、可追溯的验证闭环。已验证的 A0 两区颜色数学、参数、指纹和默认 `sku-pilot` 入口均未改变。

本版解决四类上一版无法严谨回答的问题：证据不足时是否仍会继续授权；不同类别能否采用不同置信度门；一个区域应当追哪一种参考；模型结果到底怎样与人工真值比较。

## 已落地能力

### 1. 证据不足明确失败关闭

- 肤色种子少于最低像素时，图像局部肤色先验返回全零，脸和身体编辑授权关闭。
- 服装种子少于最低像素时，服装候选与编辑授权关闭。
- 诊断记录 `skin_colour_seed_insufficient_edit_disabled` 或 `garment_colour_seed_insufficient_edit_disabled`。
- 检测到脸但无法形成可靠肤色种子时进入质量失败标记，而不是取消颜色约束后继续。

### 2. 按类别/分组设置置信度

`fine-masks` 新增 `--confidence-policy`。JSON 可以分别设置脸、手臂、服装、鞋、包、头发等类别和组合区域的阈值。每个区域的报告会记录实际阈值、覆盖率、均值、像素数、可用状态和失败原因。

示例策略位于 `configs/fine-confidence-policy.example.json`。其中数字只是偏保守的起点，必须用真实哨兵集校准，不能当成已证明的生产阈值。

### 3. 对象角色与参考来源契约

`precision-match` 现在必须显式提供：

- `object-id`：被调整对象的稳定标识；
- `sku-role`：背景、皮肤身份、头发身份、目标 SKU、配饰或保护对象；
- `reference-policy`：指定场景、已批准 SKU 锚点、源对象保持或保护；
- `reference-id`：实际参考图的 SHA-256。

不合法的角色/区域/参考组合直接拒绝。`other_garment` 和 `protected_object` 不能通过此入口改色。当前 CLI 同时校验 SKU Profile 指纹、对象所属 SKU、已确认的场景或服装锚点，以及实际参考文件 SHA-256。这里的 `confirmed` 来自 SKU Profile 的显式确认动作，不等于平台外部审批，所以所有结果仍为 `accepted=false`。

### 4. 边界残差诊断

部位追色报告新增边界像素、内部像素、边界与内部的中位变化量、二者比值以及极端突降标记。它能发现一类明显的“内部已变色但边缘突然不变”的接缝风险，但不能替代真实图像上的发丝、透明材质和反光验收。

### 5. 人工真值验证命令

新增 `validate-fine`，把模型预测的 ATR18 标签图与人工复核真值逐像素比较，输出：

- 每个类别和组合区域的 precision、recall、IoU；
- 容差边界 precision、recall、F1；
- 跨服装/皮肤/头发/配饰角色泄漏率；
- 像素准确率、当前真值中已出现类别的宏平均；
- 输入文件 SHA-256、阈值和失败原因。

```sh
batch-color validate-fine \
  --predicted-label-map validation/predicted.png \
  --truth-label-map validation/reviewed-truth.png \
  --required-region garment \
  --required-region skin \
  --min-iou 0.80 \
  --min-boundary-f1 0.70 \
  --max-cross-role-leakage 0.01 \
  --report validation/report.json
```

`checks_passed=true` 只表示这张预测相对这张人工真值达到给定阈值，不表示照片调色合格，也不表示模型在未见数据上达到同样水平。

## 正确的验证顺序

1. 由人工在原尺寸转正图上建立 ATR18 真值，至少覆盖近景、全身、遮挡、发丝、相近色服装和复杂配饰。
2. 真值制作人员与最终抽检人员分离；修改后保留新版本，不覆盖旧真值。
3. 模型输出预测标签和逐像素置信度，不缩放真值来迁就模型输出。
4. 用 `validate-fine` 测类别 IoU、边界 F1 和跨角色泄漏。
5. 用 `fine-masks` 的类别阈值将不可靠像素划入 unknown。
6. 仅对通过角色和参考来源契约的区域生成追色候选。
7. 对最终图片另做服装色差、肤色、纹理、裁切、边缘和整套一致性验收。

## 尚未完成

- 仓库没有随附或批准任何 ATR18 模型权重；本版没有真实模型精度数字。
- 没有用户人工真值哨兵集，因此示例阈值尚未校准。
- `sku_approved_anchor` 已绑定 SKU Profile 确认记录与实际参考图哈希，但尚未读取平台外部审批系统。
- 产品平铺图仍是证据，不会在缺少服装真值蒙版和材质策略时自动改变 A0 颜色目标。
- B1 仍是独立可选工具，尚未自动叠加进入 23 套默认批处理。
- 项目根目录仍没有用户选定的项目许可证；代码、模型权重、训练数据和客户素材的权利必须分别确认。

因此，0.5.1 可以称为“验证就绪”，不能称为“精准能力生产验收完成”。

## 本机回归结果

在 macOS / Python 3.12.13 上以源码路径运行完整测试：149 项通过、0 失败、0 跳过；其中包含真实 macOS Vision EXIF 几何集成测试。该结果证明当前工程回归和本机原生辅助程序可复现，不等于 ATR18 真实模型精度验收，因为仓库仍没有模型权重和人工真值数据集。
