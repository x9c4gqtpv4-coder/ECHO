# 0.4.0a2 当前源码与批处理状态

## 结论

0.4.0a2 是按 SKU 独立处理的实验候选，不是生产画质批准。默认 SKU 路径只分为背景和整个人物：

- 背景的中间调、色偏与有限对比度追本 SKU 的 `指定场景`；
- 人物标准由本 SKU `成品动作*` 的归一化中心图产生，再叠加场景冷暖/明暗方向；
- 服装、皮肤和头发使用同一条人物变换，避免局部分层接缝；
- 每张图独立计算有限参数，不跨 SKU 共用标准。

## 2026-08-30 实数据执行

- 输入：23 个 SKU，143 张成品动作；
- 输出：23/23 SKU、143/143 张候选均成功写入；
- 运行方式：macOS Apple Silicon，两线程上限，按 SKU 串行；
- 特殊输入：一张 PNG 含 253–255 的近不透明 Alpha，异常像素约 0.0565%。只在明确策略、最低 Alpha 不低于 253 且比例不高于 0.1% 时保留 RGB 并丢弃 Alpha；原图未修改；
- 所有候选保持 `accepted=false` 且要求人工复核。

## 语义质量路径

代码同时包含可选的 Apple Vision 姿态/面部/手部证据和 MediaPipe 六类概率蒙版，用于服装、皮肤、头发、配饰与冲突区的检测或实验。当前默认两区调色不依赖 MediaPipe 模型，模型权重不进 Git。

## 边界

- 现在是 8-bit sRGB 无损 PNG 输出，不是 16-bit/RAW 工作流；
- 全自动指标不能替代人工视觉验收；
- 少数图会因新增裁切、过渡检测或套系容差而保持 review；
- 不宣称“完美无色差”或“绝无色块”。
