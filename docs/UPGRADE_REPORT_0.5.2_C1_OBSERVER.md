# 0.5.2 C1 相对照明与色调只读观察层

## 交付结论

0.5.2 新增 `c1-relative-illumination-v1`，用于分解已渲染 sRGB 源图和参考图之间的表观中性轴、相对曝光型增益和显示色调差异。它是只读诊断层，不是自动白平衡、不是新的追色渲染器，不进入当前 SKU 批处理。

## 不可破坏的契约

- A0 冻结函数、参数、单次渲染策略和 Golden 指纹未修改。
- C1 开启或关闭都不改变 A0 像素输出，不否决 A0。
- C1 报告固定为 `status=review`、`accepted=false`、`pixel_output_changed=false`。
- C1 没有候选图像输出参数，没有像素修改权限。
- 生产依赖仍只有 NumPy/Pillow，未加入 OpenCV、Colour、PyTorch 或模型权重。

## 实现能力

### 相对曝光型增益

在解码线性 sRGB 中计算 P10/P25/P50/P75/P90 亮度分位点，将各分位点比值表达为 stops。中位数表示相对增益，分位点离散度表示“单纯曝光”假设是否足够解释差异。

该值命名为 `relative_exposure_like_stops`，不宣称恢复拍摄 EV。

### 曝光与色调区分

分位点 stops 大体平行时，才标记为可由相对增益解释。阴影、中间调和高光残差分开报告；不平行时输出 `compound_or_composition_unstable`，不将复合曲线或构图差误报为曝光。

### 表观冷暖证据

- 没有中性蒙版：只从低彩度、非截断、可用亮度像素生成 `hypothesis_only`。
- `human_confirmed` 或 `same_entity`：必须同时提供源图和参考图中性蒙版，否则拒绝分析。
- 仅显式中性证据可输出 McCamy 近似的表观 CCT/mired；自动证据 CCT 固定为 `null`。
- Duv 在尚未加入可验证的黑体轨迹方法前固定为 `null`，不伪造精度。

### 空间稳定性

源图和参考图各自分为 3×3 归一化空间块，分别计算局部曝光型差和中性轴偏移。空间离散过大时，只输出复合光照/表面色/构图不稳定警告，不给出可执行白点计划。

## 证据和运行身份

报告绑定：

- 源图、参考图及所有蒙版 SHA-256；
- C1 源码文件哈希与聚合指纹；
- 阈值配置和配置指纹；
- NumPy/Pillow 版本；
- 观察器 ID、Schema 和 `pixel_authority=none`。

## 未完成的事

- 未证明 C1 在真实 SKU 上比 A0 判断更准。
- 未校准真实图的阈值和置信度。
- 未实现 CAT、曝光、色调或 3D LUT 候选渲染。
- 未将 C1 接入 23 套 SKU 批处理。
- 未实现物理白点、Duv、真实 EV 或相机响应恢复。

## 本机验证

- Python 3.12.13 / Apple Silicon Mac。
- 完整回归 157 项通过、0 失败、0 跳过。
- 已知 +0.5 stops 合成扰动识别在量化容差内。
- 显式中性蒙版下的暖偏方向识别正确。
- 非平行色调曲线未被报告为单纯曝光。
- A0 实际指纹与冻结值仍为 `c4bc9ce14df5191571331b86791bd37324fdfea35cfc02db64a5d5de1138ad7f`。
- 真实 `test_01` 背景只读分析输出约 `+0.139401` stops 和 `target_warmer`；由于没有人工中性证据，白点正确降级为 `hypothesis_only`，且未生成图片。

## 下一道准入门

只有完成合成已知扰动、独立真实 SKU 标签和 A0/C1 匿名盲测后，才能进入 C1 Planner。当前版本不应根据 C1 报告自动修改、否决或批准任何图片。
