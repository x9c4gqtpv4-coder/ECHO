# 后续开发顺序 · 0.3.2 后

当前完成与验证情况见 [升级报告](UPGRADE_REPORT_0.3.2_2026-08-27.md)。下面均为下一阶段计划，不是功能完成声明。

## 已修复的基础

统一输入方向与 sRGB 处理；显式区域保护；受约束亮度映射；文件别名防护；候选与批准分离；内容签名缓存；复核状态保留；无损母版复读校验。

新增格式精度、数值边界、空间模型可信度、暂存回滚与退化缓存重试。强制终止后的自动恢复仍未实现。

0.3.2 新增私有参考标准包、双侧实际蒙版留存、参考像素与配方绑定、加载时复算、旧 JSON 降级。数值合法、证据一致、采样语义正确和画质通过仍是不同概念。

## 下一步

1. 0.4A：源图与参考图分别建立人工复核的区域基准；明确保护、未知边界和调色权限，另留未用于调参的验收样例。
2. 0.4A：先建立商品保护和最小画质门，覆盖额头、颈部、发际线、色块、断阶、色边及最终编码；不能用更好的平均追色分数抵消这些失败。
3. 0.4B：背景与皮肤独立目标、有限候选与不改候选；不用背景统计代替肤色，不把不同构图的 x/y 当作同一照明位置。
4. 0.4C：验证皮肤基线后加入头发和明确授权的商品策略；保留默认保护，不能等到这里才开始保护商品。
5. 0.5：人工基准下证明算法成立后再接自动语义分割、未知区域分流和批处理复核。初期仍不自动批准。
6. 恢复支线：增加安全的只读恢复检查、锁所有者与哈希判断、幂等恢复和 SIGKILL 故障注入；无人值守前必须完成，不阻止有人看护的区域实验。
7. 需要时再单独评估完整高位深路径和更复杂算法，必须证明实际收益；8-bit 转存成 16-bit 文件不能恢复已经损失的信息。

## 不变的边界

最终产品目标仍是背景与人物分区标准化，背景模式只是可控的起点。默认串行、按需分析、原尺寸分块处理；真实图片留在本机。没有完成标注和验收之前，不承诺自动追到完全一致，也不承诺任意图片绝无新增伪影。
