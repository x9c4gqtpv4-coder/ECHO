# 背景色彩 Profile

0.3.2 新建标准使用 .bcp 单文件证据包（Profile schema v5 / Bundle schema 1），包含规范化参考图、实际参考蒙版、统计、诊断、生成参数与实现身份。加载时重新计算，不能凭 JSON 中 trusted=true 启用空间路径。

它仍不是皮肤、头发或商品的独立色彩标准。所有结果必须人工复核。

本目录两个 v2 文件是历史测试配置，不自动覆盖。符合数值约束的 v2/v3/v4 JSON 与单独 v5 JSON 仍可读取，但仅供未验证的全局实验；新任务从原参考图重建 .bcp，不是修改扩展名。

旧 JSON 不包含参考图片；新 .bcp 包含客户参考像素与路径元数据，必须留在本地私有 data 目录，不上传 GitHub。所有 .bcp 已被 Git 忽略。当前示例 runtime JSON 是规划参数，不会被 CLI 自动加载。
